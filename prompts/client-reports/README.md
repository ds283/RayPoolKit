# Board — client-reports

**Opened:** 2026-10-27 · **Board:** [`IMPLEMENTATION_STATE.md`](IMPLEMENTATION_STATE.md)

This is a board with no prompts, in the form of DatastoreKit's `inherited-issues`. It holds issues
in the package that a client project found and reported here, each until a campaign of this
repository takes it over. Each entry is complete: what the package does, what the client saw, the
impact and a next step, with the package's code cited at this repository's commits. The client's
own board keeps the original measurement; nothing here depends on reading it.

A campaign that acts on one of these issues takes it over: the entry moves to that campaign's
board's §3, and its row moves in [`docs/OPEN_ISSUES.md`](../../docs/OPEN_ISSUES.md), in the same
commit. Nothing else is done here.
